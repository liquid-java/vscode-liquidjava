# Read a diagnostic

For an assignment that violates a refinement:

- **Found** describes the value the verifier inferred.
- **Expected** describes the constraint the value must satisfy.
- **Location** takes you to the relevant source code.
- A **Counterexample** shows values that violate the constraint, when available.
- A **Hint** suggests a next step, when available.

Use **View related context** to inspect the facts at the error. Fix the Java code or its annotation, then save or verify again to check the result.
